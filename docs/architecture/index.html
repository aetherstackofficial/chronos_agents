architecture

Code padhte waqt mili zaroori baatein

  • Engine abhi crash karega: engine/server.py mein aapka local (uncommitted) edit init_sim line comment karta hai, lekin agli logger.info(...) line abhi bhi run_id use karti hai → start par NameError.
  • Docker mein Gemini sirf News Scorer ko milta hai: docker-compose.yml mein GEMINI_API_KEY sirf oracle ko diya hai, isliye bridge ke Copilot aur Narrator Docker mein hamesha offline fallback par chalte hain.
  • Docker mein strategy sandbox nahi: bridge container mein docker CLI nahi hai, to user code subprocess mein chalta hai (sirf memory/CPU guard, security nahi). Local Docker mode mein bhi container --network host par chalta hai.
  • Time Machine ka data generate kiya hua hai: 5 crisis tapes code khud banata hai (crisis jaisi shape), ye asli market data nahi hai.
  • Monte Carlo ki limit 400 hai: run_fan ka max_paths=400 (default 60) — protocol doc aur explainer video mein 500 likha hai.
  • Results sirf memory mein: bridge restart hote hi Results Store khali; scripts files bachte hain lekin Docker volume par nahi hain.
